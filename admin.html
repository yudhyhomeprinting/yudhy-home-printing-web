🛠️ Admin — Yudhy Home Printing

Update foto website langsung dari GitHub

1. Hubungkan GitHub

Masukkan GitHub Personal Access Token hanya di halaman ini. Token tidak disimpan ke repository. Jangan pernah mengirim token kepada orang lain.

Gunakan token dengan izin Contents: Read and write untuk repository ini saja.

2. Pilih foto yang ingin diganti

Pilih JPG, PNG, atau WebP lalu tekan Upload & Ganti. Perubahan masuk ke GitHub dan biasanya perlu beberapa menit sebelum terlihat di website.

Catatan keamanan

GitHub Pages bersifat statis. Halaman admin ini memanggil GitHub API dari browser. Untuk penggunaan jangka panjang, sebaiknya nanti kita buat sistem admin dengan login dan penyimpanan foto khusus agar lebih aman.
