🛠️ Admin — Yudhy Home Printing

Update foto website langsung dari GitHub

1. Hubungkan GitHub

Halaman ini menggunakan GitHub API. Masukkan Personal Access Token GitHub Anda saat akan mengubah foto. Token hanya dipakai di browser ini dan tidak ditulis ke file website. Jangan membagikan token kepada orang lain.

Token sebaiknya memiliki akses Contents: Read and write hanya untuk repository yudhyhomeprinting/yudhy-home-printing-web.

2. Pilih foto yang ingin diganti

Pilih file JPG/PNG/WebP. Setelah klik Upload, file lama pada lokasi tersebut akan diganti dan website akan mengikuti perubahan setelah GitHub Pages selesai memperbarui.

Catatan penting

Ini adalah halaman admin sederhana untuk GitHub Pages, bukan sistem login profesional. Jangan memasukkan token ke kode atau commit ke repository. Untuk toko yang lebih besar, nanti kita bisa pindahkan pengelolaan produk ke database/storage seperti Supabase agar update foto tidak perlu menyentuh GitHub.
